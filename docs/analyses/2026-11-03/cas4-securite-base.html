2. Ce qui sera fait, dans l'ordre
  • Générer un mot de passe fort (24 caractères, jamais affiché)
  • Vérifier la connexion avec le compte d'administration
  • ALTER USER 'prestige'@'localhost' IDENTIFIED BY …
  • Mettre à jour le pool Payara (alias prestige-db) et le fichier de configuration (chiffré)
  • Tester la nouvelle connexion ; sinon revenir à l'ancien mot de passe
  • Purger les copies de domain.xml et noter la rotation dans le journal
Confirmer : changer le mot de passe maintenant (coupure ≈ 10 s) Annuler Premier clic : « Changer le mot de passe » → le bouton devient « Confirmer… » ; second clic : exécution. Aucune fenêtre.
