    • EcartsInventaireCoherenceTest : 6 000 cas ;
    • ExplicationPrevisionCoherenceTest : 8 000 séries ;

  • Bilan avant / après :
    • Crayon : un refus (doublon, numéro invalide, Échap, sans le droit) n'écrit rien en base. Un enregistrement écrit le téléphone (et l'adresse d'un client standard), rien d'autre. Les clients d'essai sont retirés à la fin.
    • Bandeau : « Non » ne change rien. « Oui » retire exactement les produits annoncés, et les stocks restent inchangés.
    • Sélecteur de période, icônes, écarts, prévision : rien n'est écrit, et les tests le vérifient.
  • Cas variés :
    • cinq clients de types différents (standard, assurance), avec un numéro absent, invalide ou valide ;
    • doublon du même type refusé, doublon d'un autre type accepté ;
    • période sans début ou sans fin, hors bornes, illisible ;
    • paramètre de nettoyage à 0 et à 1 ;
    • réserve changée entre deux impressions ;
    • trois tailles d'écran.
